## 🏭 Saw-Stage Defect Early-Warning System – OctWave 3.0

**Group Project • 2026**

🏆 **Top 10 Finalist from 208 Teams**

**Python • Scikit-learn • Random Forest • TCN • Pandas • Google Colab**

Built an industrial machine-learning system to identify hidden Saw-stage quality defects before components reach the Milling stage.

- Engineered **129 predictive features** from industrial sensor signals
- Trained a **500-tree Random Forest classifier**
- Achieved **66.7% recall and 95.2% precision**
- Achieved a **2.22% false-alarm rate**
- Benchmarked the Random Forest against a **Temporal Convolutional Network**
- Validated fixed-time-prefix detection while cutting was still in progress

🔗 **[View GitHub Repository](https://github.com/savandikodithuwakku/Saw-Stage-Defect-Early-Warning-System)**

## ⚡ Steel Industry Energy Forecasting Model

**Ongoing • 2026**

**Python • Scikit-learn • Random Forest • Pandas**

Developing a short-term industrial electricity-demand forecasting model using a real-world steel-industry dataset.

- Built a **15-minute-ahead electricity demand forecasting model**
- Identified and removed severe data leakage
- Engineered calendar, lag, and rolling-average features
- Trained a Random Forest model with an **MAE of 4.33 kWh**
- Achieved approximately **70% error reduction** compared with the seasonal-naive baseline
